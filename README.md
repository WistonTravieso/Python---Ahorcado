# Python---Ahorcado

Este proyecto consiste en un juego del ahorcado basado en consola. El jugador adivinará letras de una palabra oculta (como un título de película) dentro de un número limitado de intentos incorrectos. Las palabras se cargarán aleatoriamente desde un archivo de texto simple.

main.py – donde comienza el juego.

game.py – contiene la lógica del juego.

wordlist.txt – una lista de palabras posibles para el juego (puedes empezar con 10-20).

utils.py – funciones auxiliares como validar la entrada o mostrar el estado actual.
